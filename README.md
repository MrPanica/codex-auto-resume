# Codex Auto-Resume Watchdog

Автономный системный трей-сторож для OpenAI Codex / ChatGPT Desktop на Windows 11.
Отслеживает ошибки выполнения целей (лимиты модели, обрывы стрима, сбои контекста) и автоматически и бесшумно возобновляет выполнение без потери фокуса и сворачивания окон (включая полноэкранные игры в borderless-режиме).

## Возможности

- **Системный трей Windows**: нативное контекстное меню через Win32 API (`TrackPopupMenu`) с отображением текущего статуса, активных целей и переключателем в один клик.
- **Окно настроек Fluent Dark**: диалог настроек на PyQt6 с поддержкой темной темы Windows 11, сплошной непрозрачной отрисовкой без дефектов прозрачности.
- **Мультиязычность (i18n)**: полная локализация на русском и английском языках с автоопределением системного языка Windows.
- **Фильтрация ошибок**: включение/отключение распознаваемых ошибок, возможность добавления собственных текстовых шаблонов ошибок.
- **Выбор проектов**: фильтр проектов/чатов, для которых разрешено автоматическое возобновление.
- **Тонкие тайминги**: регулировка паузы перед повтором (2–60 сек), кулдауна (2–30 сек), интервала опроса и максимального числа попыток.
- **Автозапуск**: интеграция с автозагрузкой Windows и авто-активация при запуске `ChatGPT.exe`.
- **Бесшумное возобновление**: прямое управление через UI Automation (`Invoke()`), не отбирающее фокус у запущенных игр и полноэкранных приложений.

## Структура файлов

- `codex_tray_app.py` — главное приложение в трее Windows (фоновый поток сторожа + PyQt6 трей).
- `settings_gui.py` — окно настроек на PyQt6, менеджер настроек и локализации.
- `toggle_guardian.vbs` — тихий VBS-скрипт переключения/запуска (привязан к ярлыку на рабочем столе).
- `icon.ico` — иконка приложения.
- `requirements.txt` — зависимости Python.

## Установка и запуск

```powershell
pip install -r requirements.txt
pythonw codex_tray_app.py
```
